# Locked Rulings Register

Active Rulings: 0

This register is empty on purpose. Standing rulings, the ones that apply to all future work, live in the five Framework files. A new user working from these files has no locked rulings yet, so a Stage 2 or Stage 3 packet built from them has no register entries to carry and verifies without any.

As you work through your own chapters, record each locked ruling here with its own LR ID. Never reuse an ID.
